# FruitWorks Website

A responsive, single-page B2B website for FruitWorks, an independent hardware engineering studio. Built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Files
- `index.html` — site source
- `assets/fruitworks-wordmark.svg` — supplied FruitWorks wordmark
- `assets/founder-aamir.jpg` — founder portrait
- Other `assets/` files — hardware project visuals used in the portfolio

## Publish with GitHub Pages
1. Create or open a GitHub repository for the website.
2. Upload the contents of this folder (`index.html`, `README.md`, and `assets/`) to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site.

The site uses Google Fonts for Space Grotesk, so the font is fetched from Google Fonts when online; the rest is static and needs no backend.
